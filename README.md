One job title (24 characters) for make.fun's Weirdest Job Title: Blind Judge Showdown bounty: **"Coffin Parking Attendant"** — a parking attendant, a real and mundane job, with one hilariously specific twist: the vehicles are coffins. It reads instantly, sounds like a real posting, and lands the joke on the first read. The program writes the title to `$MAKEFUN_OUTPUT_DIR/entry.txt`, exactly as the gate requires: UTF-8 text of 1 to 60 characters, not only white space, with no trailing newline.

## Run it

```sh
python3 main.py
```

The harness sets `MAKEFUN_OUTPUT_DIR`; without it the program falls back to `/output`. Run the test suite with:

```sh
python3 -m unittest discover -s tests -v
```
